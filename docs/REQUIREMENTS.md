## Decisions (agreed 2026-10-10)

- **Stack:** Tauri 2 + Rust core, Svelte frontend. Targets: Linux and macOS first, then Android.
- **Dictionary data:** open data (Wiktionary via kaikki.org, Open English WordNet, GCIDE/Webster 1913, Moby Thesaurus, CMUdict) plus the official Merriam-Webster API with entries cached for offline use. Oxford, Merriam-Webster and Cambridge are not scraped (copyright and terms of service); Cambridge has no free API.
- **UI:** Oxford Learner's-style look, without Oxford branding.
- **Tutor notes:** currently on paper; from now on they're written in the in-app editor using `=`, `≈`, `≠` and antonym syntax.
- **Barron's:** *Essential Words for the GRE*, 4th ed. (PDF, owner's copy). Parsed locally into `private/` and never committed or distributed.
- **On-device AI:** NPU → GPU → CPU (Mac: Apple Neural Engine via CoreML; S24 Ultra: Hexagon NPU via QNN).
- **Note photos:** taken or added in the app and uploaded to `syncd` on Ubuntu. OCR runs on Ubuntu first, falling back to the device NPU, and produces a draft note that the owner reviews before accepting.
- **"Ask agents":** manually triggered only (agent quota is limited). Claude Code and agy on Ubuntu transcribe the photo, discuss disagreements, and propose a note. The owner verifies it line by line in the app, with daily-cap and mode controls.
- **Note symbols:** `=` same meaning, `≈` roughly similar, `><` opposite, `⍯` different/commonly confused (e.g. imbibition vs osmosis). `≠` is accepted as the same relation as `⍯`.
- **Server:** `lhan.duckdns.org`. Port 25 on the home Wi-Fi (`Anan` / `Anan 5g`, LAN address 192.168.1.7, reserved in the router), port 5025 everywhere else. VPNs can interfere, and the app shows whether the server is online.
- **Git:** local checkpoints at each working milestone.
